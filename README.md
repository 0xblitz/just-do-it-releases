# Just Do It

Eine einfache Aufgaben-App für macOS mit Projekten, Terminen, globaler Schnelleingabe und Desktop-Widget.

## Download

**[Just Do It für Mac herunterladen](https://github.com/0xblitz/just-do-it-releases/releases/latest/download/Just-Do-It.dmg)**

Der Link lädt immer die neueste veröffentlichte DMG. Die enthaltene App ist mit Apple Developer ID signiert und von Apple notarisiert.

Voraussetzung: macOS 14 oder neuer. Unterstützt werden Macs mit Apple Silicon und Intel-Prozessor.

## Installation

1. `Just-Do-It.dmg` per Doppelklick öffnen.
2. **Just Do It** auf **Programme** ziehen.
3. Die App aus **Programme** starten.

Das DMG-Fenster zeigt diese Anleitung und enthält einen Link zur Apple-Hilfe.

Falls macOS meldet, dass nur Apps aus dem App Store erlaubt sind: **Systemeinstellungen → Datenschutz & Sicherheit → Apps erlauben von → App Store & bekannte Entwickler**. Bei einer anderen Warnung hilft [Apples Erklärung zu den verschiedenen Meldungen](https://support.apple.com/de-de/102445).

## Automatische Updates

Die App prüft bei laufender Anwendung automatisch auf neue Versionen und lädt sie herunter. Die Installation erfolgt normalerweise beim Beenden der App. Über **Just Do It → Nach Updates suchen …** lässt sich die Prüfung auch manuell starten.

Die ZIP-Datei und `appcast.xml` in den Release-Dateien dienen weiterhin dem automatischen Updater.

Aufgaben und Projekte werden lokal auf dem jeweiligen Mac gespeichert. GitHub liefert nur die Installationsdatei und Update-Informationen.
